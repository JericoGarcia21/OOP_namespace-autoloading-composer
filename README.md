# PHP Namespaces and Autoloading Demos

This project has two independent examples. Use only one folder at a time; the examples do not share class files or autoloaders.

- [`without-composer/`](without-composer/README.md) demonstrates manual `require_once` loading and a custom SPL autoloader.
- [`with-composer/`](with-composer/README.md) demonstrates Composer PSR-4 autoloading with an `Authentication` service.

Each folder has its own `app/` classes and its own instructions. Open a terminal in the folder for the demo you want to run.
